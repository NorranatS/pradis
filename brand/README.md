# Brand

- **Name:** แม่ประดิษฐ์ · Mae Pradit (wordmark: MAE PRADIT), confirmed 2026-10-07
- **Product lines:**
  - **ประดิษฐ์ถัก · Pradit Knit**: "ถักด้วยมือเท่านั้น เครื่องจักรเลียนแบบไม่ได้" (crocheted only by hand; no machine can copy it). Yarn and soft rope yarn. Hats, shoulder bags, phone bags, coasters.
